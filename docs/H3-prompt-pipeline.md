# H3 提示词链路：增强器 ↔ H3 格式化 边界与兼容性

> **目的**：明确 `Prompt_Enhancer`（内容层）与 `H3_API_PromptFormatter`（格式层）的职责边界与衔接约定，避免两节点互相干扰、重复处理或格式冲突。
> **适用范围**：`minimaxH3_统一工作流`（888 视频反推 → 988 增强器 → 989 格式化 → MiniMaxH3ReferenceToVideo）。
> **模板**：988 → `templates/参考生视频.txt`（参考生视频流程）/ `templates/文生视频.txt`（T2V 流程）；989 → `templates/H3视频提示词格式化.txt`。

---

## 一、链路总览

```
888 视频反推(AILab) ──动作参考文字──┐
                                    ▼
987/992 素材封装(动作参考/<夭夭>) → 988 增强器(内容层) → 989 H3格式化(格式层) → H3
```

**核心分工一句话**：**增强器管「说什么内容」，格式化管「按 H3 规矩怎么说」**。增强器输出的是内容层中间产物，不写六段式；格式化把它转成 H3 六段式。

---

## 二、职责边界

| | 增强器 988 | H3 格式化 989 |
|---|---|---|
| **定位** | 内容层：素材 + tag + 用户提示词 → 画面内容描述 | 格式层：内容 → H3 六段式 |
| **输入** | LLM + 素材（动作参考/角色图）+ 已选 tag + 用户提示词 | LLM + 增强器输出文本 + 视频时长 |
| **输出** | 内容层自然语言段落（含 `<夭夭>` 标签、台词原文、动作/镜头/声音线索） | H3 六段式（subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music） |
| **是否懂 H3 格式** | ❌ 不需要——不知道六段式、`[Shot N]` 时间戳、`<Picture N>` | ✅ 唯一负责 H3 格式的节点 |

---

## 三、增强器负责（内容）

1. **内容组织**：动作参考文字为骨架，增强为完整画面描述——主体动作、场景、镜头编排、时序承接、环境动态。
2. **镜头编排（自主）**：按内容判断单/多镜头；景别明显跳变（全景↔特写）、情绪转折可切镜；镜头数量与切分点由 LLM 自主定（模板「切镜头依据」节）。
3. **标签**：沿用素材封装器标签 `<夭夭>` 指代角色，**不做 H3 标签转换**。
4. **台词**：如实保留用户提示词中的台词原文（不翻译、不改写），标注说话人 + 说话动作同步。
5. **外观**：禁描述 `<夭夭>` 外观（由参考图提供），只写功能性身体部位。
6. **声音线索**：动作声/环境声/配乐方向（供格式化生成 soundscape/music 的素材）。

## 四、格式化负责（格式）

1. **H3 六段式结构**：六小节固定顺序，段名固定。
2. **标签体系**：`<夭夭>` → `<Picture 1>` 转换（「输入素材说明兼容」节）；`<Subject N>`/`<Video N>`/`<Audio N>` 体系建立。
3. **对白格式**：台词包 `<d>[语言] 原文</d>`，说话人 `(Sx)` ID，画外音 `off-screen` 等。
4. **镜头规范化**：`[Shot N]` 时间戳（递增）、剪切措辞（cuts/transitions）、镜头数量定版——**不重新分配镜头，只规范化格式**。
5. **音轨层生成**：从增强器的声音线索生成 `overall_soundscape` / `non_diegetic_music` 实质描述。
6. **素材说明处理**：识别「图片N<标签>：角色」素材行，转换标号，**不原样输出**。
7. **外观（双层一致）**：`<Picture 1>` 只作标签引用，禁描述外观（参考换人场景）。

---

## 五、兼容性约定（防互相干扰）

| # | 项 | 增强器（988） | 格式化（989） |
|---|----|--------------|--------------|
| 1 | **标签** | 输出 `<夭夭>`（素材标签） | 转换 `<夭夭> → <Picture 1>`，建立 H3 标签体系 |
| 2 | **对白** | 如实输出台词原文，不套 `<d>` | 包 `<d>[语言] 原文</d>`、说话人 ID |
| 3 | **镜头** | 自主编排单/多镜头、切分点 | 规范化 `[Shot N]` 时间戳/措辞，不重新分配 |
| 4 | **素材说明行** | 代码会前置「图片1<夭夭>：角色参考」 | 识别并转换，不原样输出该行 |
| 5 | **声音** | 输出动作声/环境声/配乐方向线索 | 据此生成 soundscape/music，不凭空编 |
| 6 | **外观** | 禁描述 `<夭夭>` 外观 | 禁描述 `<Picture 1>` 外观（双层一致） |
| 7 | **输出形态** | 内容层自然语言段落 | H3 六段式（不接收内容层以外的东西） |

**互不干扰原则**：
- 增强器**永远不碰**：六段式、`[Shot N]` 时间戳、`<d>` 包裹、`<Picture N>`/`<Subject N>`、`<夭夭>`→`<Picture 1>` 转换。
- 格式化**永远不碰**：镜头分配、内容增删、台词原文改写、tag 优先级判断。
