# 预设制作规约（Preset Specification）

> 本规约**供 agent 制作预设（presets/*.json）时参考**：JSON 格式、约束、质检清单。
> 提示词增强器的 **tag 预设**：一个预设 = 跨多个篮子的一组 tag 捆绑（一键填篮子）。
> 复杂风格（如「天宫」）涉及构图/景别/光线/氛围/色彩等多个维度，一个 tag 描述不了——预设把它们打包。
> 节点加载时把 `presets/` 目录下所有 JSON 文件读进预设池；增删预设 = 增删文件，不改节点代码。
> 系统设计（节点如何消费预设）见设计文档 `DESIGN.md` §5-§7——本规约讲「JSON 怎么写」，设计文档讲「怎么设计」，不冲突。

## 1. 目录与文件规则

| 项 | 规则 |
|---|---|
| 预设目录 | `presets/`（节点包根目录，与 `baskets/`、`dict.json` 同级）|
| 文件粒度 | 一个预设一个 JSON 文件 |
| 文件命名 | `{key}.json`；NSFW 变体 `{key}.nsfw.json`（`.gitignore` `*nsfw*` 忽略，本地保留不上远程）|
| 部署目录 | 运行副本 `custom_nodes/ComfyUI-bsawang/presets/`（与仓库同步）|

## 2. 文件格式

示例 `presets/天宫.json`：

```json
{
  "key": "天宫",
  "label": "天宫（宏大仙宫）",
  "guidance": "天宫：东方神界巨构场景，**先写景、后写人**…（应用时注入 system prompt 的整段场景引导）",
  "tags": {
    "主题风格": ["仙侠"],
    "构图风格": ["引导线构图", "对称构图"],
    "景别": ["大远景"],
    "光线": ["黄金时刻", "逆光"],
    "氛围情绪": ["空灵", "庄严"],
    "色彩": ["低饱和", "冷暖对比"]
  }
}
```

### 字段表

| 字段 | 必填 | 说明 |
|---|---|---|
| `key` | ✅ | 预设唯一键；= 文件名（不含 `.json`）；加载器兜底用文件名 |
| `label` | ✅ | 显示名（预设 chip / 列表展示）|
| `guidance` | | 应用预设时注入 system prompt 的**整段场景引导**（跨篮子描述，如天宫构图规则）；从原篮子 option_guidance 拆分而来 |
| `tags` | ✅ | `{篮子key: [tag, ...]}`：应用预设时**覆盖**所涉篮子的当前选择；篮子 key 必须存在于当前字典 |

## 3. 约束

- `tags` 的篮子 key 必须存在于 `dict.json + baskets/` 合并后的字典（不存在 → 应用时跳过并提示）
- `tags` 的 tag 值**不必**已存在于篮子 options——应用预设只填篮子状态；增强器运行时把选中的 tag 传给 LLM
- 应用语义 = **覆盖所涉篮子**（替换该篮子当前选择），未涉及的篮子不动；应用后可自由微调
- `key` 全局唯一；NSFW 变体 `key` 不得与通用版重复

## 4. 制作流程

1. **定风格**：明确要捆绑的维度与 tag 值（对齐 `resources/prompts/标准/` 描述标准，如天宫主题描述标准）
2. **写文件**：按 §2 格式填 `key/label/description/tags`
3. **质检**：按 §5 清单自检
4. **部署**：复制到运行副本 `presets/`，重启 ComfyUI（增强器/Tag 库编辑「刷新」亦可）

## 5. 质检清单

- [ ] `key` 全局唯一、不含 `/ \` 非法字符
- [ ] `tags` 的篮子 key 都在当前字典内
- [ ] `tags` 非空
- [ ] NSFW 变体命名 `{key}.nsfw.json` 且 key 不冲突

## 6. 消费方

- **Prompt_Enhancer**：面板「预设」tab，点预设 → 覆盖所涉篮子（读 `/bsawang/prompt_enhancer/dict` 的 `presets` 字段）
- **Tag_Library**：预设层管理（应用/保存/删除），保存走 `POST /bsawang/tag/save_preset`
- **Tag_Reverse**：「存为预设」把反推采纳后的 tag 集合存成预设
